# wechat-accounts Specification

## Purpose

提供微信公众号的搜索与详情查询能力，优先从平台本地数据库返回结果以控制第三方调用成本，并对每条结果标注数据来源、采集时间与覆盖范围，避免把平台收录范围误解为全网数据。

## Requirements

### Requirement: 公众号搜索

系统 MUST 支持按关键词分页搜索公众号，结果优先来自本地数据库；响应 MUST 返回当前页数据、页码、每页数量，以及表示「本地库中符合条件记录数」的 `total`，MUST NOT 把该值表述为全网匹配总数。

#### Scenario: 本地命中关键词
- **WHEN** 用户提交关键词且本地库存在匹配账号
- **THEN** 系统返回分页结果并附带本地 `total`

#### Scenario: 本地未命中且允许冷启动查询
- **WHEN** 本地库无匹配且该请求满足受控实时查询条件
- **THEN** 系统可发起受限的第三方查询，写入结果后返回，并记录本次调用用量

#### Scenario: 参数非法
- **WHEN** 页码小于 1 或每页数量超出允许范围
- **THEN** 系统返回参数错误的标准错误结构

### Requirement: 公众号详情

系统 MUST 提供按内部 ID 查询公众号详情的能力，返回名称、微信号（如有）、头像、简介、最近同步时间等可用字段；当某字段数据源未提供时 MUST 返回 `null` 而非伪造值。

#### Scenario: 查询存在的公众号
- **WHEN** 请求一个已收录公众号的内部 ID
- **THEN** 系统返回其基础资料与最近更新时间

#### Scenario: 查询不存在的公众号
- **WHEN** 请求一个不存在的内部 ID
- **THEN** 系统返回记录不存在的标准错误结构

### Requirement: 数据来源与覆盖范围标注

公众号相关响应 MUST 标明数据来源供应商与最近同步时间；在未证明覆盖范围足够前，前端展示 MUST NOT 宣称结果为全网完整数据。

#### Scenario: 展示同步时间
- **WHEN** 用户查看公众号详情
- **THEN** 页面显示该账号数据的来源与最近同步时间

#### Scenario: 数据覆盖范围受限
- **WHEN** 平台仅收录部分公众号
- **THEN** 搜索结果与排行榜区域显示「仅覆盖平台已收录账号」类说明，而非「全网」表述
