# Spec Delta

## ADDED Requirements

### Requirement: 手机号与密码注册登录

系统 MUST 支持以手机号 + 密码注册与登录；密码 MUST 以加盐哈希存储，MUST NOT 明文或可逆方式保存；手机号 MUST 唯一且在注册时做格式校验。

#### Scenario: 注册成功
- **WHEN** 用户提交未被占用的手机号与符合规则的密码
- **THEN** 创建账号并允许其登录

#### Scenario: 手机号已存在
- **WHEN** 注册时手机号已被占用
- **THEN** 返回明确的「手机号已注册」错误，不创建重复账号

#### Scenario: 密码错误
- **WHEN** 登录时手机号存在但密码不匹配
- **THEN** 返回统一的「手机号或密码错误」，不泄露账号是否存在

### Requirement: 微信扫码登录

系统 SHOULD 支持微信扫码登录：按微信开放平台「网站应用」OAuth2 流程生成扫码登录、接收回调并用微信身份换取本地账号会话；当未配置微信凭据时 MUST 回退到可用的 mock 登录以便联调，且 mock 登录 MUST 仅在非生产环境生效。

#### Scenario: 真实扫码登录
- **WHEN** 已配置微信凭据且用户扫码并确认授权
- **THEN** 系统据微信返回的身份创建或关联本地账号并建立会话

#### Scenario: 未配置凭据回退
- **WHEN** 未配置微信凭据（开发环境）
- **THEN** 提供 mock 登录入口完成登录流程，且生产环境不提供 mock 登录

### Requirement: 会话与登出

登录成功后系统 MUST 签发可撤销的会话，并以 HttpOnly、SameSite 的 Cookie 承载；系统 MUST 提供「当前用户」与「登出」能力，登出 MUST 使该会话失效。

#### Scenario: 读取当前用户
- **WHEN** 持有效会话请求当前用户
- **THEN** 返回该用户的身份与准入状态

#### Scenario: 登出
- **WHEN** 用户登出
- **THEN** 该会话立即失效，后续携带旧会话的请求视为未登录

#### Scenario: 会话失效或过期
- **WHEN** 会话已过期或被撤销
- **THEN** 受保护请求返回未登录错误

### Requirement: 未登录访问控制

未登录用户 MUST NOT 使用主应用的数据功能；访问受保护页面 MUST 被重定向到登录页，访问受保护接口 MUST 返回 `401`。

#### Scenario: 未登录访问首页
- **WHEN** 未登录用户访问受保护页面
- **THEN** 被重定向到登录页

#### Scenario: 未登录调用数据接口
- **WHEN** 未登录请求调用受保护的数据接口
- **THEN** 返回 `401` 与统一错误信封
