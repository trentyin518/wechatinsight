# Spec Delta

## ADDED Requirements

### Requirement: 数据查询鉴权与准入

所有 `/api/v1` 数据查询端点（账号搜索、账号详情、账号文章列表、文章详情、指标历史）MUST 要求持有效会话且登记审核通过的用户；未登录 MUST 返回 `401`，已登录但未通过审核 MUST 返回 `403`，并 MUST 复用统一错误信封。公开健康检查 `/health` 不受影响。

#### Scenario: 未登录调用查询接口
- **WHEN** 无有效会话调用数据查询端点
- **THEN** 返回 `401` 与统一错误信封

#### Scenario: 未通过审核调用查询接口
- **WHEN** 已登录但登记未通过审核的用户调用数据查询端点
- **THEN** 返回 `403` 与「未通过审核」错误码

#### Scenario: 已审核通过调用查询接口
- **WHEN** 已登录且登记审核通过的用户调用数据查询端点
- **THEN** 正常返回查询结果
