# Proposal

## Why

当前平台完全公开、无任何身份体系：任何人可直接搜索与浏览数据，既无法识别使用者、也无法按用户分层提供服务，更无法满足「先登记资质、审核通过后使用」的商业数据产品诉求。参考西瓜数据（data.xiguaji.com）的做法——先用微信扫码 / 账号登录，首次使用前强制填写一份信息登记表（获知途径、用户类型、公司、证明材料、联系人、需求），审核通过后才开放使用——需要为平台补齐身份与准入闭环，既保护数据资产，也为后续按用户/资质分层打下基础。

## What Changes

- 新增**身份认证能力**：
  - 手机号 + 密码的注册与登录（密码加盐哈希存储）。
  - 微信扫码登录：按微信开放平台「网站应用」OAuth2 接入，凭据经环境变量配置；**凭据缺失时自动回退到 mock 登录**（本地/开发可完整联调，生产配置真实凭据即切换真实扫码）。
  - 会话管理：登录后签发可撤销的会话（HttpOnly Cookie），提供「当前用户」「登出」能力。
  - 访问控制：未登录访问受保护页面/接口时重定向到登录页或返回 `401`。
- 新增**准入登记（Onboarding）能力**：
  - 首次登录后强制弹出信息录入表单，字段与截图一致（获知途径、用户类型、公司名字、证明材料上传、姓名、联系电话为必填；需求为可选，带「其他」自定义项）。
  - 证明材料上传（营业执照 / 工牌 / 名片 / 账号截图等），保存于服务端并可被审核人查看。
  - 提交后进入**待审核**状态；**审核通过前不可使用主应用**，被驳回可查看原因并重新提交。
  - 管理员审核能力：查看待审登记、通过 / 驳回（附原因）。
  - 审核结果通知：应用内状态提示（随登录/轮询刷新）；短信通知作为可插拔通知通道预留（需短信服务商，暂不在本次接入）。
  - 访问门禁：已登录但未完成登记 → 引导到登记页；登记待审核 → 待审核页；被驳回 → 驳回页并可重提；审核通过 → 进入主应用。
- **BREAKING**：主应用（首页/搜索/详情/文章等数据查询）从「完全公开」改为「需登录且审核通过后方可使用」。数据查询接口在未认证或未通过审核时返回相应错误码。

## Capabilities

### New Capabilities

- `authentication`: 用户身份与登录——手机号+密码注册/登录、微信扫码登录（真实 OAuth2 + mock 回退）、会话签发与撤销、当前用户与登出、以及基于会话的访问控制与未登录重定向。
- `onboarding`: 首次准入登记与审核——信息录入表单（字段/必填/自定义「其他」/需求可选）、证明材料上传、提交与审核状态流转（待审核/通过/驳回）、管理员审核、审核结果通知，以及基于审核状态的访问门禁。

### Modified Capabilities

- `query-api`: 数据查询端点（账号搜索、账号详情、文章列表、文章详情、指标历史）由公开访问改为**要求已认证且登记审核通过的用户会话**，未满足时返回 `401`（未登录）/ `403`（未通过审核）并复用统一错误信封。

## Impact

- **后端**：新增用户/会话/登记/上传相关 ORM 模型与 Alembic 迁移；新增 `auth`、`onboarding`（含管理员审核）路由与依赖（`get_current_user`、`require_approved`）；为既有 `accounts`/`articles` 路由挂载鉴权依赖；新增密码哈希、会话令牌、上传存储、微信 OAuth 客户端（含 mock 实现）、通知接口等模块；配置项（微信 AppID/Secret/回调、管理员引导账号、上传目录、会话有效期）注入 `config.py` 与 `.env.example`。
- **前端**：新增登录页（微信扫码 + 账号密码）、注册、信息录入表单（含文件上传与「其他」联动）、待审核/驳回页；新增会话读取与访问门禁（中间件或服务端校验 + 重定向）；`lib/api.ts` 改为携带会话（Cookie）并处理 `401/403`；`layout` 增加登录态与登出入口。
- **API/契约**：新增认证与登记相关端点；数据查询端点新增鉴权要求（BREAKING）。
- **安全/合规**：密码加盐哈希、HttpOnly+SameSite Cookie、会话可撤销、上传文件类型/大小校验、敏感信息最小化；`.env` 不入库。
- **依赖**：后端可能新增密码哈希库（如 `passlib[bcrypt]` 或 `bcrypt`）与 OAuth/HTTP 客户端（复用现有 HTTP 客户端优先）；前端不新增 UI 框架依赖。
- **运维**：新增上传目录持久化与环境变量；管理员账号通过环境变量引导创建。
