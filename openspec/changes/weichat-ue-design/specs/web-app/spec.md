# Spec Delta

## MODIFIED Requirements

### Requirement: 首页搜索

首页 MUST 以分区式产品首页呈现，至少包含：主搜索入口、平台能力/价值说明、真实数据覆盖概览、分类或账号入口、内容更新区块与数据来源/覆盖范围说明；主搜索入口 MUST 能跳转到搜索结果页。

#### Scenario: 从首页发起搜索
- **WHEN** 用户在首页输入关键词并提交
- **THEN** 跳转到搜索结果页并展示分页结果

#### Scenario: 展示数据范围说明
- **WHEN** 用户查看首页
- **THEN** 页面显示数据来源与覆盖范围说明

#### Scenario: 分区式布局
- **WHEN** 用户查看首页
- **THEN** 页面按 Hero、能力说明、数据覆盖概览、分类/账号入口、内容更新、底部说明的顺序分区展示

## ADDED Requirements

### Requirement: 首页真实数据覆盖概览

首页 MUST 展示数据覆盖概览，其中的数值 MUST 来自平台真实数据（如已收录公众号数、已收录文章数、接入数据源数、最近数据更新时间）；无数据时 MUST 显示「暂无」或「暂不可用」，MUST NOT 显示编造的数字，也 MUST NOT 用 0 代替缺失。

#### Scenario: 展示真实覆盖数据
- **WHEN** 用户查看首页数据覆盖概览
- **THEN** 各指标显示与平台真实收录情况一致的数值，并标注最近更新时间

#### Scenario: 尚无数据
- **WHEN** 平台尚无任何收录数据
- **THEN** 概览显示「暂无」或「暂不可用」，而不是 0 或虚构数字

### Requirement: 首页能力与价值说明

首页 MUST 以卡片或等效形式说明平台核心能力与价值（如数据真实性、统一数据源、指标溯源、历史快照），文案 MUST NOT 承诺平台尚未提供的能力或数据。

#### Scenario: 展示能力说明
- **WHEN** 用户查看首页能力区块
- **THEN** 页面展示与平台实际能力一致的能力/价值说明，不出现无法兑现的功能承诺

### Requirement: 首页内容更新区块

首页 SHOULD 展示最近更新或最新收录的内容（文章或账号），每项 MUST 标注其数据来源与采集时间，并能跳转到对应详情页；无可展示内容时 MUST 显示空状态而非空白或占位假数据。

#### Scenario: 展示最近更新
- **WHEN** 平台存在可展示的最近更新内容
- **THEN** 首页内容区块列出这些内容并标注来源与采集时间，点击可进入详情页

#### Scenario: 无更新内容
- **WHEN** 平台暂无最近更新内容
- **THEN** 内容区块显示明确的空状态

### Requirement: 首页分区局部降级

首页任一数据驱动区块（覆盖概览、内容更新等）加载失败时 MUST 局部降级为该区块的错误/空状态，且 MUST 保持搜索入口与其余区块可用，MUST NOT 因单区块失败导致整页不可用。

#### Scenario: 覆盖概览数据获取失败
- **WHEN** 首页覆盖概览所需数据获取失败
- **THEN** 该区块显示可重试的错误或「暂不可用」状态，搜索与其他区块仍正常可用
