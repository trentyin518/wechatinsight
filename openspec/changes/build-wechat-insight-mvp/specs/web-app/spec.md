# Spec Delta

## Purpose

提供面向用户的第一版查询界面，围绕「搜索公众号 → 查看详情 → 浏览历史文章 → 查看文章指标」的数据闭环，清晰展示数据来源、采集时间与缺失状态，避免用虚构数字填充图表。

## ADDED Requirements

### Requirement: 首页搜索

首页 MUST 提供公众号搜索入口、已收录账号分类入口与数据覆盖/更新说明，并能跳转到搜索结果页。

#### Scenario: 从首页发起搜索
- **WHEN** 用户在首页输入关键词并提交
- **THEN** 跳转到搜索结果页并展示分页结果

#### Scenario: 展示数据范围说明
- **WHEN** 用户查看首页
- **THEN** 页面显示数据来源与覆盖范围说明

### Requirement: 公众号结果与详情展示

搜索页 MUST 展示账号名称、微信号（如有）、简介、头像、最近更新时间与收藏占位，并支持分页；详情页 MUST 展示基础资料、最近更新时间与历史文章列表。

#### Scenario: 搜索无结果
- **WHEN** 关键词在本地无匹配
- **THEN** 页面显示明确的空状态，而不是错误或伪造数据

#### Scenario: 打开公众号详情
- **WHEN** 用户点击某公众号
- **THEN** 进入详情页并展示资料与历史文章

### Requirement: 文章详情与指标展示

文章详情页 MUST 展示标题、原文链接、所属公众号、发布时间与可获取的互动指标，并显示指标采集时间；当数据源仅提供单次指标时 MUST 仅展示该时刻数据，MUST NOT 生成历史曲线。

#### Scenario: 展示单次指标
- **WHEN** 文章仅有一次指标快照
- **THEN** 页面展示该时刻的指标值并标注采集时间，不显示趋势图

#### Scenario: 指标缺失
- **WHEN** 某指标为 `null`
- **THEN** 页面显示「暂不可用」或留空，而不是显示 0

### Requirement: 错误与缺失状态

前端 MUST 区分并友好呈现空数据、记录不存在、数据源不可用与网络错误；第三方故障 MUST NOT 导致整个站点不可用。

#### Scenario: 数据源暂时不可用
- **WHEN** 后端返回数据源不可用
- **THEN** 页面提示稍后重试并保留可用的本地内容

#### Scenario: 加载历史文章失败
- **WHEN** 文章列表请求失败
- **THEN** 页面显示可重试的错误状态，而不是空白或崩溃
